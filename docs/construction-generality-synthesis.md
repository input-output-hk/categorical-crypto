## Executive result

This is a **completed read-only research deliverable within the explicit corpus below**, not an implementation or a claim to exhaust all literature. The source census covers every named implemented setup/view at the supplied proof boundary, keeps proof layers separate, and explicitly includes the actual IPDL interpreter and in-progress CSP work. Six parallel semantic reports contain **89 ten-field records: 88 construction/coverage records and one canonical-source-access record**. Those records are deliberately not 88 claims of novelty: many subtract already-existing generic machinery.

The main result is that the repository's reusable baseline is substantially richer than ordinary composition: it already includes contextual kernels, setup transfer/refinement/regrading, two-sided quotients, quantitative and query-scaled composition, family/small-error collapse, rated audit/event transport, coupling/fundamental-lemma/potential rules, both game-level and machine-run deferred sampling, stochastic SSP state simulations, generic machine spans and world-indexed run-following. A new universal probability, coupling, lazy-sampling, or composition framework would duplicate real APIs.

The strongest genuinely new arbitrary-QUC candidate is small: **package security together with designated-mode availability, retaining two independent errors and compatible middle caps**. The strongest two-independent-theory work is **native typed-run/locality adapters to existing sampling APIs** (SSP–TaskPIOA, with IPDL's existing adapter preserved), followed by **test/ancilla-density interfaces for the existing ITM and SSP transfer proofs**. Larger shared work is structured: typed open-network linking, scheduler information, nominal/session allocation, and carefully separated guarded/instantaneous/stored-state feedback. None follows merely from the name UCSetup or from QUC's test-error enrichment.

## 1. Corpus, standardness, and completeness claim

A construction is included when an inspected primary source actually defines its operation, proof rule, theorem or counterexample, and it is relevant to a constructed carrier/source theory. A familiar name without a native contract is not enough. Protocol case studies are used only as witnesses or obstructions, not as a purported census of arbitrary encryption, MAC, commitment or MPC protocols.

Completeness has two different scopes:

1. **Repository coverage:** all declared setup/view groups in the source census have a disposition, including quantitative, negligible, observation and grade variants. Aliases and proof layers are not counted as additional native models.
2. **Literature coverage:** every inventoried foundational construction in the explicitly listed inspected sections has a classification and implementation/generalisation disposition. This is not a claim to cover every theorem in every cited book, all variants of every formalism, or all worldwide literature. The reports state their examined sections, version differences, meaningful exclusions and inaccessible sources. In particular, canonical UC full-paper access is an explicit source gap, not hidden behind an IITM or SUC substitution.

## 5. Quantifier, equality, resource and observation audit

These are load-bearing distinctions, not terminology preferences.

### 5.1 Five independent layers

1. **Carrier equality** may be free syntax, state-isomorphism, a simulation closure, or a quotient. It is not automatically the observation relation.
2. **Bare kernel** `≈ℰ` compares the chosen tests. PM has an explicit bare/U separator and false GradeStable.
3. **U agreement** adds every ancillary grade/context. The two-sided monoidal quotient additionally pads on both sides for tensor congruence.
4. **UC order** adds a simulator converter: `∀a.∃s.∀W,test`. Dummy form fixes `s₀` before all tests. A coupling, state relation, native FSim or context-specific schedule is not that converter.
5. **Native security** also fixes interface, admissibility/runtime, scheduler, state/initialization and observation semantics. A formal setup morphism without coverage is not a completed native computational theorem.

### 5.2 Error scopes which must not be exchanged

Suppressing the common comparison predicate:

| View | Actual existential scope |
|---|---|
| Canonical local-negligible UC | `∃s. ∀W,e,m. ∃ negligible δ. ∀i` |
| Small-image negligible UC | `∃s. ∀W,e. ∃ negligible δ. ∀m,i` |
| Stronger global quantitative witness | `∃s,δ. negligible δ ∧ ∀W,e,m,i` |

The elementary diagonal `d_m(n)=1` exactly when n=m is a concrete logical local/uniform obstruction, **not a claimed fully represented PM contextual separator**. For query-aware transitivity the error is `ε₁(q)+ε₂(scale q r)`, not unscaled addition. Measured serial composition additionally certifies the actual first real process and simulated continuation. Numerical error, task-depth grade, interface/choice-site grade, query count, runtime and retained-memory bits are distinct indices.

### 5.3 Absence of output is not one universal effect

- PM/SSP observe **both false and true masses**; false and divergence/failure are distinguishable. Per-verdict ε bounds imply at most2ε failure-mass difference, not automatically ε.
- Task disabled tasks are successful **stutters**, retaining normalized probability, not aborts.
- IPDL pending `Get=None` is an ordinary successful reply, read **before** that turn's quiescence; it is not SSP's outer cemetery outcome.
- CSP distinguishes termination, deadlock, divergence and refusal according to the selected relation. Weak bisimulation can identify divergence and deadlock; FD/FSim do not have interchangeable laws.
- Prefix-hit probability can retain a witnessed bad prefix even if a later continuation dies; completed-run flag observation can be zero. Existing code contains the bad-then-dead separator.
- A future useful Task QUC cannot bound all unrestricted rational reward functions by one finite absolute ε: scaling a distinguishing reward scales its discrepancy. Bound rewards or track their norm.
