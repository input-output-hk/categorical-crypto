# The ITM setup: interactive Turing machines, ports reading

Design plan, 2026-10-09. §6 steps 0–7 are implemented and typechecked on branch `itm-setup`; §6
records where the tree's names and choices differ from the sketches below, which are otherwise
not typechecked. `file:line` refers to this worktree.
This plan refines `docs/uc-setup-landscape.md` §3 and corrects it where §5.7 says so.

## 1. Summary

- **Setup.** `StdUC 𝕋ᴹ ℰᵀ`. `𝕋ᴹ` is the free monoidal category (`Categories.FreeMonoidal`, already in
  the tree) on finite-table Turing machines between port interfaces (trees of bitstring ports):
  morphisms are ITM systems, hom-equality is generated by the monoidal axioms, and tests are
  `ℰᵀ = ℰᵒ ∘F Fᴾ.op`. Closest setup: protocol-rewrite; `𝕋ᴹ` presents the non-wide, non-full part of
  `𝔾ᵒ` generated by TM runs.
- **`itm⇒prot`** is a `StdUCMorphism` with a strict `Fᴾ` (a leaf runs to `send` in `Dₚ`) and
  `ν = pullbackᵛ` (Epi and Mono). `F (g ∘ f) = F g ∘ F f` holds definitionally.
- **`itm⇒iso`** is a `StdUCMorphism` from a *second* observation of `𝕋ᴹ`, via a strict mirrored `Fᴿ`
  (a leaf becomes its run relation). The triangle closes only on deterministic leaves.

## 2. The source model

The Canetti PDF (ePrint 2000/067, revision 2020-02-12) could not be retrieved; see
`docs/kb/sources/litreview/BLOCKED-URLS.md`. All `[Can20 …]` numbers below are taken from
`chevalier2026` §4 (pp. 14–18), which cites that revision. Its bib key is `canetti2020uc`.

- **ITM** `[Can20 Def 4]`: tapes for identity (code, id), activation, read-only read-once
  randomness and outgoing messages, plus externally writable input, subroutine-output and backdoor
  tapes. Configurations and ITIs: `[Can20 Def 5]`.
- **Activation** `[Can20 §3.1.2]`: the one active ITI runs until it writes one message (the recipient
  runs next), self-deactivates (the environment runs next, with no message) or halts. `hofheinz2013`
  §2 agrees. In `kusters2020iitm` §3.1.2 one message arrives on one input tape and *at most one*
  leaves; by §3.3, no output activates the master.
- **Ports reading.** Static wiring by tape name (`kusters2020iitm` §3.1.1), fixed parties
  (`canetti2015suc` §2.2). Dynamic ITIs, `!` and identities are dropped.
- **Composition** is the union with shared ports connected, ping-ponging until a message leaves
  (`hofheinz2013` §2 Def 2; `kusters2020iitm` §3.2 `S₁ | S₂`). **Tensor** is the union with disjoint names.
- **Equality.** `EXEC_{π,A,Z}(k,z)` is `Z`'s bit `[Can20 §4.1]`, or 0 on non-termination
  (`hofheinz2013` §2). The advantage `|Pr[X=1] − Pr[Y=1]|` must be negligible, or 0 when perfect
  `[Can20 Def 8]`. Emulation is ∀A ∃S ∀Z `[Can20 Def 9]`; the dummy adversary is complete
  (`[Can20 §4.3.1, Claim 11]`; `hofheinz2013` Def 12, Thm 19). PPT: `[Can20 §3.2]`; `hofheinz2013`
  Defs 5, 7, 8 (§5.6).
- **The tree's readout** (`UC/Model/Observation.agda:48-76`) runs one closed system and compares
  *both* verdict masses within every ε > 0: perfect, no `k`/`z`, divergence ≠ `false`. 𝕋 inherits it.

| source | `𝕋ᴹ` |
|---|---|
| control, tapes | `TM` record (§3.3) |
| random tape | `flip`: one `coinₚ uniform-Bool` per bit |
| activation up to one write | `runᵀᴹ` = `iterₚ` until `send` (§3.4) |
| at most one output; silence activates `Z` | exactly one output (G discipline); "return control" is an explicit reply |
| systems and their union | free monoidal terms (§3.1) |
| `k`, PPT, balanced `Z`, corruption | dropped (§5.6) |

## 3. The `StdUC` instantiation

### 3.1 The free monoidal category (reused: `src/Categories/FreeMonoidal.agda`)

The tree already has the construction, `--safe --without-K`:
- `FreeMonoidalData {v ; X ; mor}` and the module `FreeMonoidal d`, which provide:
  - `ObjTerm` (`unit`, `_⊗₀_`, `Var`);
  - `HomTerm` (`var`, `id`, `_∘_`, `_⊗₁_`, λ/ρ/α);
  - `_≈Term_`, the 21 monoidal-category generators `idˡ` … `pentagon`, with `σ` gated by `v`.
- `FreeObjInterp`, the object map computed from the atoms alone. Its comment (`:405-409`) says this
  "lets a caller state a generator's interpretation type before fixing the generator signature", which
  is exactly what `leafᵒ` (§3.6) needs.
- `FreeFunctorData {⟦v⟧ ; ⟦_⟧ᵖ₀ ; ⟦_⟧ᵖ₁}` with the module `FreeFunctor`:
  - `⟦_⟧₁`;
  - `⟦⟧-resp-≈` (`:466-490`), where each case plugs one law of the target;
  - `freeFunctor`;
  - `isMonoidal-freeFunctor`, with identity `ε`/`⊗-homo` (`:501-511`).
- `fromMC`, `noSymmetric`, and `Bind` (change of generators over the same atoms, `:345-390`).

Only the strong packaging is missing. `docs/uc-setup-symbolic.md` adds it as well (its step 2);
whichever plan lands first adds it, once.

```agda
freeStrongMonoidal : (ffd : FreeFunctorData d) → StrongMonoidalFunctor (FreeFunctor.FreeMonoidalM ffd) (FreeFunctor.CM ffd)
freeStrongMonoidal ffd = record
  { F = freeFunctor
  ; isStrongMonoidal = record
    { ε = record { from = C.id ; to = C.id ; iso = record { isoˡ = C.identity² ; isoʳ = C.identity² } }
    ; ⊗-homo = niHelper record { η = λ _ → C.id ; η⁻¹ = λ _ → C.id ; commute = λ _ → id-comm-sym
                               ; iso = λ _ → record { isoˡ = C.identity² ; isoʳ = C.identity² } }
    ; associativity = … ; unitaryˡ = … ; unitaryʳ = … } }   -- the proofs at `:508-510`
  where open FreeFunctor ffd
```

Every arrow out of `𝕋ᴹ` is `freeStrongMonoidal` of some `FreeFunctorData`. So `F` is strict, and
`F (g ∘ f) = F g ∘ F f` holds definitionally. Generators are identified only when they are `≡`:
identifying pointwise-equal tables would need a `runᴾ-ext` on each side.

### 3.2 Port interfaces

```agda
{-# OPTIONS --safe --without-K #-}
module CategoricalCrypto.ITM.Core where

open import Categories.FreeMonoidal

data Pol : Set where ⁺ ⁻ : Pol         -- ⁺ answers out to the caller, ⁻ queries in (`Iface.agda:3-5`)
open FreeMonoidalHelper Mon Pol using (ObjTerm; unit; _⊗₀_; Var)
Ports Bits : Set
Ports = ObjTerm ; Bits = List Bool     -- `Data/Bits/Codec.agda` encodes typed payloads into Bits
Port⁺ Port⁻ : Ports → Set              -- finite: ⊥ / ⊤ / ⊎
Port⁺ unit = ⊥ ; Port⁺ (Var ⁺) = ⊤ ; Port⁺ (Var ⁻) = ⊥ ; Port⁺ (A ⊗₀ B) = Port⁺ A ⊎ Port⁺ B
In Out : Ports → Ports → Set           -- a hom A ⇒ B reads Pos A ⊎ Neg B (`UC/Machine.agda:62-63`)
In A B = Port⁺ A ⊎ Port⁻ B ; Out A B = Port⁻ A ⊎ Port⁺ B

⟦_⟧ : Ports → Iface                    -- ⊥ₚ is 𝒱ₚ's initial object: ⟦ unit ⟧ = 𝟭ᴵ (`Dictionary.agda:117`)
⟦ unit ⟧ = ⊥ₚ ⇿ ⊥ₚ ; ⟦ Var ⁺ ⟧ = Bits ⇿ ⊥ₚ ; ⟦ Var ⁻ ⟧ = ⊥ₚ ⇿ Bits ; ⟦ A ⊗₀ B ⟧ = ⟦ A ⟧ ⊗ᴵ ⟦ B ⟧
decode : (A B : Ports) → Pos ⟦ A ⟧ ⊎ Neg ⟦ B ⟧ → In A B × Bits    -- encode is its inverse
encode : (A B : Ports) → Out A B × Bits → Neg ⟦ A ⟧ ⊎ Pos ⟦ B ⟧
ports : ℕ → ℕ → Ports                  -- the count view: n positive, m negative ports
ports n m = ⨂ n (Var ⁺) ⊗₀ ⨂ m (Var ⁻)
```

**Decision: use trees, so that `F` is strict.** On trees `F (A ⊗ B)` *is* `F A ⊗ F B`, so `ε` and
`⊗-homo` are identities. The landscape's `F (n ⇿ m) = (Fin n × Bits) ⇿ (Fin m × Bits)` would
force `⊗-homo = wireᴹ join splitAt`, making every coherence law a wire equation. Counted ports
survive only for stating results, via wires `⟦ ports n m ⟧₀ ≅ ifaceᵒ ((Fin n × Bits) ⇿ (Fin m × Bits))`.
These compose to `id` in three steps: `∘-wireᴹ` (`UC/Machine/Wire.agda:100-110`) yields a stateless
`sandwichᴹ` (`Machines/Sandwich.agda:41-43`); `S.mk-cong` turns it into `wireᴹ (u₂ ∘ u₁) (d₁ ∘ d₂)`;
`wire-pure` at `pureᵏ id` (`Dictionary.agda:85-93`) gives `wireᴹ id id ≈ᴹ 𝒫.id`, and the rest is
pointwise `join-splitAt`/`splitAt-join`.

### 3.3 The TM record (decision: a finite transition table)

```agda
data Sym : Set where ␣ 𝟎 𝟏 : Sym
data Move : Set where ◁ ▷ ∙ : Move
record Tape : Set where
  constructor _‹_›_
  field left : List Sym ; here : Sym ; right : List Sym
data Instr (Q O : Set) : Set where
  run  : (q : Q) (w : Sym) (mʷ mⁱ : Move) (b : Maybe Bool) → Instr Q O  -- write, move heads, emit bit
  flip : (q₀ q₁ : Q) → Instr Q O                                        -- read one random bit
  send : (o : O) (q : Q) → Instr Q O        -- end activation: buffer on port o, resume at q
record TM (I O : Set) : Set where
  field #Q : ℕ ; start : Fin #Q ; δ : Fin #Q → I → Sym → Sym → Instr (Fin #Q) O

Gen : Ports → Ports → Set
Gen A B = TM (In A B) (Out A B)

module _ {I O : Set} (M : TM I O) where
  open TM M
  Mem : Set                                 -- what survives deactivation
  Mem = Fin #Q × Tape
  blank : Mem
  blank = start , [] ‹ ␣ › []               -- the canonical initial configuration
  record Conf : Set where                   -- one activation: fresh input tape, empty buffer
    field state : Fin #Q ; work : Tape ; port : I ; input : Tape ; buf : List Bool
  δ-at : Conf → Instr (Fin #Q) O
  δ-at c = δ (state c) (port c) (here (work c)) (here (input c))
  load : Mem → I × Bits → Conf ; exec : … → Conf → Conf ; goto : Fin #Q → Conf → Conf
```

**Why a concrete table.** Leaves are only interpreted, because composition is a constructor (§3.1);
so a table costs no proofs. An abstract step function with a TM witness would need the same table
as witness, plus a product construction. `δ` has a finite domain, so it *is* a table, and one work
tape suffices. The control state persists, as in `[Can20 Def 5]`; IITM §3.1.2 keeps only work
tapes, which is equivalent.

### 3.4 Run until halt: `runᵀᴹ`

No new corecursion is needed. "Run until `send`" is Elgot iteration `iterₚ` (`Dp/Iter.agda:34-52`);
its `stepᵢ` adds one guarded delay per pass. A non-halting run has `cum` 0 everywhere, so it is
`≈ₚ botₚ` (`Dp.agda:476-478`). A halting run is `≈ₚ` its Dirac (`laterₚ-≈ₚ`, `Dp.agda:470`). The laws
are `iterₚ-fix`/`-cong` (`Dp/Iter.agda:97,181`) and `Elgotᵏ` (`Machines/Base.agda:87-258`).

```agda
{-# OPTIONS --safe --without-K --guardedness #-}
module CategoricalCrypto.ITM.Run where

open import Data.Product.Base
open import Function.Base using (case_of_)
open import Level using (0ℓ)
open import ProbabilisticLogic.Distribution.Uniform using (uniform-Bool)
open import ProbabilisticLogic.Dp
open import ProbabilisticLogic.Dp.Coin using (coinₚ)
open import ProbabilisticLogic.Dp.Iter using (Body; iterₚ)
open import CategoricalCrypto.ITM.Core
open import CategoricalCrypto.Machines.Base using (𝒱ₚ)
open import CategoricalCrypto.UC.Machine using (Proc; initˢ)
import CategoricalCrypto.Machines.Core as Core

private module MC = Core (𝒱ₚ 0ℓ)

module _ {I O : Set} (M : TM I O) where
  body : Body (Conf M) ⊤ (Mem M × (O × Bits))
  body (c , _) = case δ-at M c of λ where
    (run q w mʷ mⁱ b) → returnₚ (exec M q w mʷ mⁱ b c , inj₂ tt)
    (flip q₀ q₁)      → mapₚ (λ x → goto M (if x then q₁ else q₀) c , inj₂ tt) (coinₚ uniform-Bool)
    (send o q)        → returnₚ (c , inj₁ ((q , work c) , o , reverse (buf c)))

  runᵀᴹ : Mem M × (I × Bits) → Dₚ (Mem M × (O × Bits))
  runᵀᴹ (m , x) = mapₚ proj₂ (iterₚ body (load M m x , tt))

runᴾ : Gen A B → Proc ⟦ A ⟧ ⟦ B ⟧            -- point = returnₚ blank
runᴾ {A} {B} M = MC.mk (initˢ (Mem M) (blank M))
                       λ (m , x) → mapₚ (map₂ (encode A B)) (runᵀᴹ M (m , decode A B x))
```

### 3.5 `𝕋ᴹ` and its hom-equality (decision: intrinsic)

```agda
itmData : FreeMonoidalData {0ℓ}
itmData = record { v = Mon ; X = Pol ; mor = Gen }
open FreeMonoidal itmData using (FreeMonoidal; Monoidal-FreeMonoidal)
𝕋ᴹ : MonoidalCategory 0ℓ 0ℓ 0ℓ                  -- = FreeFunctor.FreeMonoidalM of any FreeFunctorData itmData
𝕋ᴹ = record { U = FreeMonoidal ; monoidal = Monoidal-FreeMonoidal }
```

Pulling `≈ᴹ` back along `Fᴾ` would buy nothing, since `⟦⟧-resp-≈` is already a fold, and it would block
`Fᴿ`. Let `t′` be `t` plus an unreachable state `q⋆` with `δ q⋆ _ _ _ = send o q⋆`. Then
`runᴾ t ≈ᴹ runᴾ t′`, by the pure simulation `Fin #Q ↪ Fin (suc #Q)`. But `Fᴿ t ≇ᴹ Fᴿ t′`: `t′` has
a `send`-self-loop at every `q⋆`-configuration and `t` may have none (cf. `padded-not-iso`,
`Machine/Iso.agda:46-54`). So the generated congruence is the finest under which both interpretations
exist. Consequently `F-resp-≈` is `⟦⟧-resp-≈`; `ν`'s cong is the target's `≋`, and hom-equality enters
only through `ℰᵀ`'s `F-resp-≈`. `Fᴾ` is not faithful, which is harmless: observational kernels are pulled back.

### 3.6 Tests, levels, `open StdUC`

**Tests.** A test on `A` is a `𝔾ᵒ` test `⟦ A ⟧₀ ⇒ Ωᵒ` up to `≋ᵒ`: every closure `𝟘ᵒ ⇒ ⟦ A ⟧₀` gives
the same `Obs` within every ε. So `f ≈ℰ g ⟺ Fᴾ f ≈ℰᵒ Fᴾ g`, and `f ≈ᵁ g` is `𝔾ᵒ`'s `≈ᵁ` at
ancillas `⟦ Y ⟧₀`, since strictness gives `Fᴾ (μ ∘ T₁ Y f) = μ ∘ T₁ ⟦ Y ⟧₀ (Fᴾ f)`.

**Levels.** `ℰᵀ` inherits `cs = ℓs = suc 0ℓ` from `ℰᵒ`, which is `Observable` over `∣𝔾ᵒ∣`, whose
homs are at `suc 0ℓ`. That matches `UCSetupMorphism` without lifting, although `𝕋ᴹ` sits at `0ℓ`.
An intrinsic observation on `𝕋ᴹ` would be `Setoids 0ℓ 0ℓ` (`UC/Core.agda:146`).

**Computable tests are a `Refine` target, not part of `ℰᵀ`.** Adversaries and simulators are
already computable, because grades and `sub` range over `𝕋ᴹ`. Computable *environments* form the
coarser `ℰᶜ`, which statistical ITM-UC implies for free:


`ℰᶜ` has a `ν` into `ℰᵒ` only if a *density* theorem holds: computable closures separate tests as
well as all closures do. Classically that follows by finite approximation `[INFERENCE]`.

### 4.2 `itm⇒iso : ITMᴵˢᵒ → machine-iso` ("forget to the step relation")

```agda
{-# OPTIONS --safe #-}      -- K: `Machine.UC` needs it (`same⁻¹`, :66-71); --without-K is coinfective
module CategoricalCrypto.ITM.Relational where
import CategoricalCrypto.Machine.UC as Iso   -- machines (reversed), ℰ-tests, StdSetup

⟦_⟧ᶜ : Pol → Channel
⟦ ⁺ ⟧ᶜ = Bits ⇿ ⊥ ; ⟦ ⁻ ⟧ᶜ = ⊥ ⇿ Bits        -- in ↦ Pos, out ↦ Neg (landscape §2 table)
open FreeObjInterp Mon Pol (fromMC Iso.machines noSymmetric) ⟦_⟧ᶜ   -- ⟦ A ⊗₀ B ⟧₀ = ⟦ B ⟧₀ ⊗₀ ⟦ A ⟧₀: mirrored

data Steps (M : TM I O) : Conf M → Conf M → Set where   -- finite run; `flip` takes either bit
  ε : Steps M c c
  _◂run_ : δ-at M c ≡ run q w mʷ mⁱ b → Steps M (exec M q w mʷ mⁱ b c) c′ → Steps M c c′
  _◂flip_ : δ-at M c ≡ flip q₀ q₁ → (x : Bool) → Steps M (goto M (if x then q₁ else q₀) c) c′
          → Steps M c c′
-- Sends c (o , w) m′ := δ-at M c ≡ send o q × w ≡ reverse (buf c) × m′ ≡ (q , work c)
leafᴿ : Gen A B → Machine ⟦ A ⟧₀ ⟦ B ⟧₀
leafᴿ M = MkMachine {State = Mem M} λ m i o m′ →
  Σ[ c ∈ Conf M ] Σ[ y ∈ _ ] (Steps M (load M m (decodeᴿ i)) c × Sends c y m′ × o ≡ just (encodeᴿ y))
Fᴿ : StrongMonoidalFunctor 𝕋ᴹ Iso.machines
Fᴿ = freeStrongMonoidal record { ⟦v⟧ = fromMC Iso.machines noSymmetric ; ⟦_⟧ᵖ₀ = ⟦_⟧ᶜ ; ⟦_⟧ᵖ₁ = leafᴿ }

ℰᴵˢᵒ = Iso.ℰ-tests ∘F Functor.op (StrongMonoidalFunctor.F Fᴿ)   -- Setoids (suc 0ℓ) (suc 0ℓ)
module Rel = StdUC 𝕋ᴹ ℰᴵˢᵒ
itm⇒iso : UCSetupMorphism Rel.StdSetup Iso.StdSetup
itm⇒iso = StdUCMorphism 𝕋ᴹ Iso.machines ℰᴵˢᵒ Iso.ℰ-tests Fᴿ (pullbackᵛ (StrongMonoidalFunctor.F Fᴿ) Iso.ℰ-tests)
```

**Components and obligations.** These mirror §4.1:
- `F` is `⟦_⟧₀`/`⟦_⟧₁` into `Iso.machines`. Identity and homomorphism hold definitionally, and
  `F-resp-≈` is `⟦⟧-resp-≈` into `Reverse` of `machine-monoidal` (`Machine/MonoidalCategory.agda:68-104`).
- `Φ` is `Fᴿ.monoidalFunctor`, whose `ε` and `⊗-homo` are identities.
- `κ` is `Oplax.δ`, the identity `CC.id`; its laws are discharged inside `StdUCMorphism`.
- `ν` is `pullbackᵛ`, both Epi and Mono.

The new code is `Steps`, `leafᴿ` and `decodeᴿ`. `decodeᴿ` goes via `destruct-⊗` because `Channel`'s
`⊗₀` is opaque (`Channel/Core.agda:136-140`). A leaf's image:
- is never silent (`o` is always `just`);
- has no transition on divergence;
- forgets `blank`, because machine-iso has no initial state;
- reads coins as nondeterminism, so the probabilities are lost.

**Why the source is `(𝕋ᴹ, ℰᴵˢᵒ)`, not `(𝕋ᴹ, ℰᵀ)`.** A `ν′ : ℰᵀ ⇒ ℰ-tests ∘ Fᴿ.op` would map
`≋ᵒ`-classes, which carry no state space, to `≅ᴹ`-classes (state bijections), so cong fails for
every image-based `ν′`. The constant test is not natural either: pulled back along `Fᴿ h` it gains
`Fᴿ h`'s state `[INFERENCE]`. So `𝕋ᴹ` carries two observations (`reobserve`,
`Abstract2/Morphism.agda:106-109`). A product `ℰᵀ ×ᵖ ℰᴵˢᵒ` would give one source for both arrows,
but its kernel is the useless conjunction.

### 4.3 The triangle `𝕋 → machine-iso → protocol-rewrite`

`G : machine-iso → protocol-rewrite` does not exist, so this does not typecheck today. Once `G`
exists, the triangle closes only under four conditions:
1. **Deterministic leaves**: `𝕋ᵈᴹ` from `itmDataᵈ` (`mor = Genᵈ`, tables never `flip`), embedded by `Bind`. A
   `SetupSubcategory` cannot carve it out, since `W-sub` would have to hold at probabilistic
   adversaries, and probabilistic leaves' relational images forget their distribution.
2. **`G` reads a realizer.** Beyond landscape §2's init and no-silence changes, `G` needs a `Dₚ`
   realizer as data, `W f := Σ r (stepRel ⇔ graph r)`; uniqueness alone gives no functor. `W-∘` is
   the adequacy of `TraceRel` (`Machine/Core.agda:146-159`) against the Elgot trace. On leaves the
   realizer is `runᵀᴹ M`.
3. **Mirror isomorphism.** `G` is non-strict (machine-iso's tensor is reversed, so `⊗-homo` = swap
   wires). `G₀ (Fᴿ₀ A)` and `Fᴾ₀ A` differ by a monoidal natural isomorphism of wires (§3.2).
4. **`ν`** closes after `changeKernel (𝕋ᵈᴹ, ℰᴵˢᵒ) → (𝕋ᵈᴹ, ℰᵀ)` with `G`'s `ν` (close the ancilla
   with `⊥`, landscape §2).

### 4.4 Other setups

- **Random systems** (`docs/uc-setup-random-systems.md`): `composeᵁ rewrite⇒RS itm⇒prot`
  (`CategoricalCrypto.UC.RandomSystems.Morphism`); no new obligations.
- **Causal boxes** (`docs/uc-setup-causal-boxes.md`): none (§4 there): zero-time internal rounds
  and an interleaving `⊗` have no causal-box image.
- **Symbolic** (`docs/uc-setup-symbolic.md`): none either way; soundness needs PPT environments (§5.6).
- **SSP, IPDL**: none. Their steps are Agda functions, not tables, and a TM activation is
  unbounded iteration, not a finite `Calls` tree.

## 5. Hard parts and risks

1. **Seal and performance.** `Fᴾ`'s laws are stated and *plugged* at the sealed bundle; receiving
   one at the transparent bundle costs about 470 s (`UC/Machine.agda:8-10`). `F₀≡` uses exported
   equations only, so no ITM module unfolds the seal; unfolding next to `StdUC` is the 12 GiB
   configuration (`Enrichment.agda:12-13`). `ℰᵀ` must use the re-exported `ℰᵒ` (a rebuilt copy
   measured 80 s against 9 s). `itm⇒iso`'s type mentions `StdSetup` at `curriedTensor machines`,
   and ascribing such types costs 9–15 min (`Machine/MonoidalCategory.agda:95-98`). `FreeFunctor.CM`
   rebuilds the bundle as `record { U ; monoidal }`. The Seal's rule 2 measured a rebuilt *transparent*
   bundle at an 8 GiB OOM, so `Fᴾ` carries an explicit type and is checked against the sealed `𝔾ᵒ`,
   where the comparison should only touch neutral projections. The step-0 spike measured these
   risks (§6 step 0). `leafᵒ` is a `subst₂` that never computes, so leaf proofs go through
   `leafᵒ-∘` and `leafᵒ-resp` (J on `F₀≡`) together with `procᵒ-∘` and `≈ᴹ⇒≈ᵒ`.
2. **Guardedness.** No new corecursion; only `Run`, `Functor`, `Setup` and `Computable` use the flag.
3. **Quotients.** None: `_≈Term_` is inductive, and test setoids come from `ℰᵒ` and `ℰ-tests`.
4. **Levels.** `𝕋ᴹ` sits at `0ℓ`; both arrows share `cs = ℓs = suc 0ℓ` via the pullbacks; `ℰᶜ`
   sits at `0ℓ 0ℓ`, which `Refine` allows.
5. **K.** `Relational` must use K, because `--without-K` is coinfective and `Machine.UC` uses K.
6. **Runtime bounds cannot be properties of morphisms.** A priori PPT has no identities, since a
   forwarder is not a priori polynomial (`hofheinz2013` Def 5, §3). Reactive PPT is not closed
   under composition (`hofheinz2013` §1.5, the double repeater). So PPT ITMs form neither a
   category nor a `SetupSubcategory`; bounds must be validity side conditions over a
   security-parameter tier, outside `StdUC` (PlanSymbolic informed). Without bounds, computable
   environments are observationally vacuous `[INFERENCE]`: at `≈ᵁ` a computable test can relay to an
   arbitrary closure through a port ancilla, and closures are dense because a depth-n readout
   inspects finitely many branches. Compare `broadbent2023` §5 (pp. 30:23–24): distinguisher
   equality is a congruence only on morphisms the distinguishers can implement.
7. **Disagreements with `docs/uc-setup-landscape.md`.**
   - §3 "the real work is `F (g ∘ f) ≈ᴹ F g ∘ F f`": definitional for systems, and UC/IITM
     protocols *are* systems (§2). Ping-pong survives only in the optional normal form (§6 step 8).
   - §3 "pull back `≈ᴹ`": this blocks `itm⇒iso` (§3.5).
   - §3 "`WideSubcategory` fails on identities": right conclusion, wrong reason. Identities are
     wires and satisfy `W-id`. The actual obstacles are `W-sub` (`WideSubcategory.agda:58`), which
     needs `W (sub c)` at *every* ambient adversary, and `subSetup` keeping `ℐ` (`:114-115`).
   - §3 "→ machine-iso: ν = inclusion (Mono)": the statistical setup has no `ν′` (§4.2); from
     `ℰᴵˢᵒ`, `ν′ = pullbackᵛ` is Epi and Mono.
   - §3 "the triangle commutes by construction": only for deterministic leaves, up to the mirror
     iso (§4.3); §2.2's uniqueness gives no functor.
   - §2 "⊎ on objects is symmetric on the nose": no, `A ⊎ B ≢ B ⊎ A` and `Channel`'s `⊗₀` is
     opaque. Strictness comes from interpreting into `Reverse` (`fromMC Iso.machines`).
   - §3 "one output = the G discipline": agreed, but it deviates from Canetti (self-deactivation
     activates `Z`, `[Can20 §3.1.2]`) and IITM (no output allowed, §3.3).
