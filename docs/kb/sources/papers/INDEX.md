# Paper archive index

Every file is named `<bibkey>.<ext>`, where `<bibkey>` is its exact BibTeX key in
`../../refs.bib`. To go from a citation in a rendered PDF to its source, look up the key
here or open `<bibkey>.pdf` directly. Companion `.txt` files are `pdftotext` extracts of
the same paper. Variant PDFs of one bibliographic entry keep the bibkey plus a
`-<variant>` suffix (e.g. `-eprint-full`, `-companion`).

Format: `<filename> — <bibkey or "no bib entry"> — <authors, short title, venue year>`
